How it works

  1. Your wallet searches for a nonce in the browser: keccak256(miner‖nonce‖anchor) must be ≤ target (real work, off the main thread).
  2. The price is quoted from priceFor(wallet, n) — a tier per wallet, never a static number.
  3. USDT is approved for the exact total (two steps), then mine(nonce, count).
  4. Proofs are single-use: one find = one batch (max 100 per transaction).

Mint proceeds

Every mint is split 75% to the holder pool (credited per token held, claimable any time) and 25% to the treasury.

Supply is unlimited, bound only by time: minting closes automatically 7 days after deployment (MINING_END) — there is no extend function.
